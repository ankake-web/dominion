## 回収時のメモ（こちら側の作業）

- 予定枚数＝**50枚**（王国25／イベント10／予言15）。Downloads の枚数を数えて突き合わせる。
- **連番＝生成順を信用しない**。全枚を実見して全単射で判別する。
- 紛らわしいペア＝**侍／忍者／大名／浪人**（全部「武士」系）、**山の社／川の社**、**茶屋／魚屋**。
- 回収先＝`asset/art/<id>.png` → `CARDS_ONLY=<ids> node tools/build-cards.js`（王国25）／
  `CARDS_ONLY=<ids> node tools/build-landscape.js`（イベント10＋予言15）。
- 絵が入ったかはファイルサイズで検算（枠＋文字だけ＝40〜70KB／絵入り＝80KB超）。
- 最後に Downloads の原本を掃除（`asset/art/*.png` と sha1 一致する PNG だけ消す）。
