## ■ 受け取り後の作業（私がやる）
1. zip の manifest.csv とアプリ側の33種を名前で突き合わせ、過不足ゼロを機械検算。
2. `asset/art/<id>.png` に配置 → 縦型32枚は `build-cards.js`、召喚は `build-landscape.js` で webp 生成。
3. ファイルサイズで絵入りを検算（縦型98KB超／横型60KB超）＋モンタージュで目視。
4. `sw.js` の VERSION を上げる。

※ 段階1（カタログ＋id 確定）が先でも、絵の生成は並行して頼める。id は英語名のスネークケースで予定：
